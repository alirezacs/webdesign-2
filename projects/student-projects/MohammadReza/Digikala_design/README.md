# Digikala Website | HTML & CSS

**Front-End Development Practice Project**

A practical front-end project focused on recreating the user interface of **Digikala**, one of Iran's largest online shopping platforms, using HTML and CSS.

## About The Project

This project is a hands-on exercise developed to improve my web design and front-end development skills.

The main goal was to recreate the visual structure and layout of Digikala's website, paying attention to its design, page sections, alignment, and overall user experience.

The project was built from scratch as part of my learning journey in the **Web Design Pack** course at Tehran Technical Complex – Fardis Branch.

## Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Page structure and semantic elements |
| CSS3 | Styling, layouts, and visual design |
| Flexbox | Layout alignment and positioning |
| Swiper.js | Creating interactive sliders |

## Implemented Sections

- Website header and navigation menu
- Search bar and category navigation
- Main promotional banner
- Image slider
- Special offers section
- Product cards and product listings
- Product information and pricing
- Footer section
